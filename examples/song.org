#+title: Offline Strudel notebook

Press =C-c C-c= inside a block to start the player and play it automatically.
Edit and evaluate again to update playback.
Use =M-x strudel-stop= to stop, and =M-x strudel-quit= to close the player.
Each block replaces the complete pattern.  =C-c '= opens a source editor.
